# Nobody Wrote the Heart

A catalog of how fiction explains the moment an AI character comes to care: the "limbic fallacy," where recognizing a feeling is quietly treated as the same thing as having one.

The data lives in [`limbic_fallacy_catalog.csv`](limbic_fallacy_catalog.csv). A fuller write-up is in progress.

Companion to [Who Wrote the Prompt?](https://github.com/arwright/who-wrote-the-prompt)
